# 01: Bursting：指定运行生成独立分析报告

**What to build:** 显式选择现有 bursting 运行，生成诊断图、汇总表与独立分析记录；支持旧入口的 HDF5 运行结果和新求解器结果，修改图表无需计算。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 输入显式包含运行编号与结果位置；检查身份、完成状态及必要字段，缺失或不兼容时明确报错，不选择最新结果。
- [x] 每次分析创建独立编号，保存实际分析参数、输入身份、相关分析源码信息、环境、日志和输出清单；全部输出保存成功后才标记完成。
- [x] 至少生成涡量平方积分（enstrophy）的时间曲线及运行汇总表；两类结果的物理定义、归一化和时间轴经核验，无法统一的量分别标注。
- [x] 分析默认拒绝失败或未完成输入；保留原始数据与计算日志，重复绘图不覆盖已有分析。
- [x] 用两类小型已保存结果验证加载、报告生成及失败路径；验证分析过程不调用求解器，并提供调用说明。
