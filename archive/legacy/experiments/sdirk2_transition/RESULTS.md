# 有外力固定步长比较：已验证的候选

后续固定相同物理配置的 gamma=1000 对照见 [GAMMA_1000.md](GAMMA_1000.md)。

已找到满足目标的参数组。在相同初值、外力、网格和步长下，小步长两种方法具有接近的二阶精度；四个连续过渡步长上 mr-SAV 的涡量与速度误差更小；再增大步长时原 SDIRK2 出现强烈数值失稳，mr-SAV 完成积分。

## 参数

- 区域：`[0,2π]²`，周期边界；最终主网格 `256²`，核对网格 `128²`。
- 黏性：`nu=0.2`；mr-SAV 参数：`gamma=5`；终止时间：`T=6`。
- 外力：涡量方程中的 `cos(x)`，幅值始终为 1，未取消外力。
- 初值：原实验 `K=10` 的确定性余弦叠加，系数 `(k²+m²)^(-3/2)`，零均值、RMS=1。
- 方法：原 `IMEX_RK2` 与 `SDIRK2_mr_SAV`，保持现有算法；`root_selection=legacy`。
- 参考：同网格 ETDRK4，1536 步，即 `tau_ref=0.00390625`；另计算 768 步作减半验证。

与原 notebook 基线相比，初值和非零外力保持不变，改变了黏性 `0.001 → 0.2`、gamma `2000 → 5` 和终止时间。这个较大黏性的算例不是原 `nu=0.001` 问题的重复计算。

## 终点误差（T=6，N=256）

下表给出涡量相对 L² 误差的原始小数；`R` 为 mr-SAV/SDIRK2。爆破项没有人为补成终点误差。

| 步数 n | 固定步长 T/n | SDIRK2 | SDIRK2-mr-SAV | R |
|---:|---:|---:|---:|---:|
| 512 | 0.011718750 | 4.17957426e-07 | 4.14877222e-07 | 0.992630 |
| 256 | 0.023437500 | 1.67563831e-06 | 1.66319502e-06 | 0.992574 |
| 128 | 0.046875000 | 6.72226369e-06 | 6.67130981e-06 | 0.992420 |
| 75 | 0.080000000 | 3.11227410e-02 | 1.80879242e-02 | 0.581180 |
| 74 | 0.081081081 | 5.55279068e-02 | 1.25080336e-02 | 0.225257 |
| 73 | 0.082191781 | 9.86106056e-02 | 9.72482086e-03 | 0.098618 |
| 72 | 0.083333333 | 1.74281517e-01 | 8.95255836e-03 | 0.051368 |
| 56 | 0.107142857 | solution_blowup | 1.23821220e-02 | -- |
| 40 | 0.150000000 | solution_blowup | 1.44362832e-02 | -- |

小步长区：两种方法的误差相差约 0.7%–0.8%，128→256→512 步的观测阶分别为 SDIRK2 `2.00424, 2.00328`，mr-SAV `2.00401, 2.00320`。这里“精度一致”指误差接近且同为二阶，不是逐点完全相同。

过渡区：`tau=0.08, 6/74, 6/73, 1/12` 对应 SDIRK2 的误差约 `3.11%, 5.55%, 9.86%, 17.43%`，mr-SAV 约 `1.81%, 1.25%, 0.97%, 0.90%`；误差分别减少约 `41.9%, 77.5%, 90.1%, 94.9%`。两种方法在这四个步长上都完成计算。

速度误差也更小：在 `tau=1/12` 时，SDIRK2 的速度相对误差约 `0.80265%`，mr-SAV 约 `0.04314%`。过渡区 mr-SAV 误差并不随步长单调变化，不把它解释为更高收敛阶。

大步长区：`tau=0.15` 时，SDIRK2 在 `t=4.95` 达到预定停止条件（涡量 RMS 已超过受迫物理上界的 141 倍），mr-SAV 完成 `T=6`，涡量相对误差约 `1.4436%`、速度相对误差约 `0.3734%`。`tau=6/56` 时也发生同类分离。

这里的“数值爆破”指按预先定义阈值检测出的剧烈非物理增长，停止时仍可能是有限浮点数；不是连续 PDE 有限时爆破，也没有把原始数据伪造为 NaN。

## 验证范围

- ETDRK4 步长由 `0.0078125` 减半到 `0.00390625`：256² 网格终点涡量相对差异 `5.03e-12`；所有四个观测时刻的最大差异 `5.85e-11`。
- 参考解 `128² → 256²`：T=6 共同网格点上的相对差异 `3.57e-14`。
- 上述四个过渡步长 `128² → 256²`：mr-SAV 的终点相对差异至多 `4.85e-8`，SDIRK2 至多 `1.46e-6`。这些差异远小于正在比较的时间误差，支持该区间的空间分辨率充分性。
- `legacy` 与 `nearest` 选根在 `n=72,74,75,40` 上的 mr-SAV 终点相对差异最大约 `3.77e-8`；该优势不依赖这两种选根策略之间的切换。未声称所有步长都唯一实根。
- 在 `tau=1/12` 下也检查了 `t=1.5,3,4.5,6`。前面三个时刻误差接近，明显优势在后期误差增长时出现。因此不声称整个时间区间均有同样幅度的精度改进。
- 独立驱动与原固定步长驱动的三种方法快照一致；保存、重载、元数据不匹配拒绝、中断后从初值重跑、失败前缀保留均作了小规模检查。
- 额外检查 ETDRK4 的单 Fourier 模态受迫解析解，最大绝对差约 `1.11e-15`。这项检查本身不证明一般非线性求解器正确。
- 独立 notebook 的全部 Python 单元在其所在目录顺序执行通过，计算开关均关闭；技能审计报告语法错误 0、存储错误输出 0，生成图片已目视检查。当前 pde 环境没有 nbformat/nbclient，因此没有宣称完成 Jupyter 内核端到端执行；没有为此次验证安装新依赖。

逐项数值和运行身份见 [validation.json](validation.json)。比较图和流场图由持久化数据生成，notebook 默认不会重新积分。

## 搜索记录与结论边界

首次搜索保留 1635 个运行文件，覆盖 52 个包含网格、选根策略的配置，含参考解与验证；1265 个完成，370 个按预定阈值停止。此计数不包含后续 gamma 对照。早期扫描与失败结果均保留在 `data/sdirk2_transition/`，最终驱动和候选数据位于其 `validated/` 子目录。不同源版本或数字类型可能对应不同身份，此数量不是独立物理算例数。

初始扫描包含幅值、外力幅值、gamma、黏性及随机相位/剪切初值；有些低 gamma 与剪切组合会显著恶化小步长误差。nu=0.05 的早期候选还表现出明显网格依赖，没有作为最终推荐。最终选择同时满足小步长误差接近、过渡区优势、数值失稳分离和空间核对的 nu=0.2 算例。

结果支持这个具体受迫算例，不能推广为任意参数下 mr-SAV 都更准确。主结论是相同步长比较，未作相同运行时间的性能结论。原 notebook、原求解器和已有用户修改均保留。
